# Android build tools

The checked-in Gradle wrapper pins Gradle 8.13 and verifies its distribution SHA-256. Use JDK 17 and Android SDK platform 36 / build-tools 36.0.0.

On Windows with an existing Android SDK:

```powershell
$env:JAVA_HOME = 'C:\path\to\jdk-17'
$env:ANDROID_SDK_ROOT = 'C:\path\to\Android\Sdk'
.\tools\build.ps1
```

For a portable Windows setup, read the [Android SDK terms](https://developer.android.com/studio/terms), then run:

```powershell
.\tools\setup-android.ps1 -AcceptAndroidLicenses
.\tools\build.ps1
```

The setup script writes only into `.android-tools` beside this project by default. It does not set persistent environment variables, install Windows services, or change virtualization settings. Add `-WithEmulator` to download an API 36 Google APIs x86_64 system image and the emulator. Hardware acceleration must already be available to run that image reliably.

`build.ps1` defaults to `assembleDebug`, `testDebugUnitTest`, and `lintDebug`. To run another task:

```powershell
.\tools\build.ps1 -Tasks @('connectedDebugAndroidTest')
```

The debug APK is written to `app/build/outputs/apk/debug/app-debug.apk`. A connected phone must have Android developer options and USB debugging enabled and must authorize this computer before installation or device tests can run.
