Shoko Remote is independently implemented against the Shoko Server API and the user-visible AniDB form.

- [AndroidX / Jetpack Compose / Room](https://android.googlesource.com/platform/frameworks/support/): Apache License 2.0.
- [OkHttp and MockWebServer](https://github.com/square/okhttp): Apache License 2.0.
- [ASP.NET Core SignalR Java client](https://github.com/dotnet/aspnetcore): MIT License; its transitive components retain their own licenses.
- [JUnit](https://github.com/junit-team/junit4): Eclipse Public License 1.0.
- [jsdom](https://github.com/jsdom/jsdom): MIT License, development tests only.
- [Sora font](https://github.com/google/fonts/tree/main/ofl/sora): SIL Open Font License 1.1; full license in `licenses/Sora-OFL.txt` and bundled with the app's assets.

Dependency license/notice metadata is retained where included by the corresponding artifacts. The build does not bundle Shoko Server, AVDump, or anime media. Shoko and AniDB names refer to the services this client interoperates with.
