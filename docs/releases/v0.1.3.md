# Shoko Remote 0.1.3 — Stable

Released November 10, 2026. The owner confirmed the installed update functions as expected.

## Included

- Shoko Server 5.3.3 sign-in, searchable unrecognized files, batch selection, server-side AVDump and progress recovery.
- Anime search automatically filled from release filenames, with group tags, episode numbers and technical suffixes removed. Manual changes are preserved.
- Native AniDB Mass Add controls, live dropdown choices, group search, local templates, advanced tracks and per-file episode/version/date editing.
- Official AniDB sign-in, review and final submission inside the app, with the final submission controlled by the user.
- Saved drafts, separate submission/recognition states, and Shoko recognition checks.
- Shoko Gray styling and Sora typography.

## Fixes

Fixes the Android launch crash introduced in 0.1.2 by filename-parser patterns. Delimiters now compile on Android's ICU engine, and an optional parsing failure leaves saved work available with manual search. Version 0.1.2 is withdrawn.

## Install or update

Download **Shoko-Remote-0.1.3.apk** from this release and open it on the phone. Install over the existing Shoko Remote app to retain its saved connection, drafts and AniDB session. Android may ask you to allow installation from the app opening the APK. Do not uninstall first.

Requires Android 8 or newer, a current Android System WebView, and access to Shoko Server through your home network or VPN. Configure AniDB/AVDump credentials on Shoko Server; sign in to AniDB separately inside the app. Full setup and workflow instructions are in the [README](../../README.md).
