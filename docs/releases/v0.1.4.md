# Shoko Remote 0.1.4 — Stable

Developed with **OpenAI Codex**, in collaboration with ichigoteguz.

## Changes

- Add **About Shoko Remote**, available from the info button in the top bar. It shows the app version and "Developed with OpenAI Codex" credit.
- Add the same development credit to the README.
- Make the repository public at the owner's request.

This update keeps the owner-confirmed 0.1.3 workflow. The remaining WebUI work is tracked in the [feature checklist](../FEATURES.md).

## Install or update

Download **Shoko-Remote-0.1.4.apk** and install over your existing copy to keep the connection and drafts. Requires Android 8 or newer and a current Android System WebView. See the [README](../../README.md) for setup.

The release includes the signed APK (package `dev.shoko.remote`, version code 5), a source snapshot, and `SHA256SUMS.txt`. Signing keys and local credentials are excluded.
