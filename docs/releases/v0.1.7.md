# Shoko Remote 0.1.7

Developed with OpenAI Codex, in collaboration with ichigoteguz.

Released November 14, 2026. This update improves the complete Files → AVDump → AniDB → Shoko recognition workflow.

## Changes

- Refresh Files on return and foreground resume, and start a fresh batch when Shoko recognizes the entire AVDump pool.
- AVDump files from several anime together, then choose a separate subset for each AniDB submission. Pending recognition groups stay visible while preparing the next anime.
- Automatically use the native editor when AniDB's signed-in form is ready; show the official page for login or browser verification.
- Native **Next** retains AniDB's EPNO/version detection and opens per-file confirmation. Editable release dates default to today in **dd.mm.yyyy** format, including conversion of valid ISO dates in existing drafts.
- Native **Add Files** submits through the official control and shows explicit success/errors. **Review on AniDB** remains optional; ambiguous submissions are never automatically retried.
- Keep the bottom navigation highlight aligned with the displayed page, including automatic return to Files, guarded redirects and restored screens.

## Install or update

Download **Shoko-Remote-0.1.7.apk** and install over your existing app to retain the saved connection, drafts and templates. Do not uninstall first. Requires Android 8 or newer and a current Android System WebView; targets Shoko Server 5.3.3.

Package `dev.shoko.remote`, version `0.1.7`, version code `8`. Assets include the signed APK, `shoko-remote-source.zip`, and `SHA256SUMS.txt`. Signing keys and local credentials are excluded.
