# Shoko Remote 0.1.5 — Local validation build

Developed with OpenAI Codex, in collaboration with ichigoteguz.

Prepared November 14, 2026 for the owner's live submission check. This is a local update; it has not been published or designated stable.

## Changes

- Refresh Files when returning to it or resuming the app, and start a fresh batch once Shoko recognizes the whole pool.
- AVDump files from several anime together, then choose a separate subset for each AniDB submission. Submitted groups remain pending while the next anime is prepared.
- Open the native editor automatically after AniDB authentication. Native **Next** retains AniDB's EPNO/version detection and opens editable per-file release dates, initially filled with today's date when blank.
- Submit through native **Add Files** and display explicit AniDB results. Optional official-page review remains available; ambiguous submissions are not automatically retried.

## Update

Package `dev.shoko.remote`, version `0.1.5`, version code `6`. Install the signed APK over the existing app to retain its saved connection and drafts. Do not uninstall first. The local release output is `app/build/outputs/apk/release/app-release.apk`.
