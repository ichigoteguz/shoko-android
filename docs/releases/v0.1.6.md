# Shoko Remote 0.1.6 — Date format correction

Developed with OpenAI Codex, in collaboration with ichigoteguz.

This local validation build corrects AniDB release dates to **dd.mm.yyyy**, as confirmed by the owner. Both the per-file default and Apply date to all use the corrected format, and labels show the same format.

Valid ISO dates saved by 0.1.5 are converted without changing their calendar date. Manual dotted dates, incomplete edits and blank fields are preserved. Shoko timestamps retain their existing format.

Package `dev.shoko.remote`, version `0.1.6`, version code `7`. Install over the existing app to retain the saved connection and draft. The verification record is maintained in [verification notes](../VERIFICATION.md). This build has not been published or designated stable.

Signed release assembly, lint, 74 JVM tests, 23 JavaScript tests and eight phone instrumentation tests passed. The signed update was installed over 0.1.5 on the owner's phone and opened successfully.
